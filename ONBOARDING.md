## O que é este ecossistema

Um sistema de automação e governança documental construído pela Diretoria de
Transformação Digital da SETIS/SES-DF, combinando repositórios GitHub como
memória institucional, skills do Claude como agentes especializados e matrizes
de conhecimento como fontes de verdade compartilhadas.

Portfólio público: https://github.com/victorarimatea/dtd-setis

## Propósito C — Quero executar uma tarefa específica

Cada instrumento tem seu próprio repositório com a skill completa.
Leia o `SKILL.md` do repositório correspondente e siga as instruções.

| Tarefa | Skill | Repositório |
|---|---|---|
| Elaborar uma PoC em saúde digital | S03 | https://github.com/victorarimatea/skill-poc-saude-digital |
| Transcrever um documento PDF para Markdown estruturado | S05 | https://github.com/victorarimatea/skill-transcricao-documental |
| Registrar uma reunião em formato institucional para o SEI | S06 | https://github.com/victorarimatea/skill-registro-reuniao |
| Criar um novo repositório no ecossistema | S01 | https://github.com/victorarimatea/skill-criador-de-skills |
| Consultar a taxonomia estruturada de saúde digital | M02 | https://github.com/victorarimatea/saude-digital-taxonomia |

As skills são autossuficientes — cada `SKILL.md` descreve todas as etapas
do processo, os padrões obrigatórios e os critérios de qualidade.
